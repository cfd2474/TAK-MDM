A storefront is a version of the ATLAS store: a shelf of apps a user may install for themselves. It reaches a device only when an App Management policy assigns it, so different devices can be offered different shelves. An offer is not a policy — nothing here installs automatically. To install an app whether the user wants it or not, make it a required app instead.
