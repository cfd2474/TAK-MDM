Agent updates

Publishing a build tells every enrolled device to replace its own agent with it, at its next check-in. Devices that are failing to apply policy are skipped until they recover, and a device is left alone until it has checked in cleanly once on the build it is already running.

There is no rollback. Breach mode

For a device in the wrong hands. Engaging it on a device's own page replaces every policy that device has with the settings below — it does not add to them.

⚠️ Nothing here can be undone on the device. Apps are uninstalled and the directories below are emptied. Taking a device back out of breach mode restores its policies, not its data: the operator doctrine is that a breached device is factory wiped and reprovisioned before it is trusted again.

Breach mode deliberately stops short of a factory wipe, because a wiped device stops reporting where it is — which is the one thing still worth having from a tablet somebody else is holding.

Apps removed

Every app and plugin in the library, blocked — uninstalled where the device allows it, hidden where it does not. Generated, not edited: the list is taken from the library at the moment a device is breached.

The ATLAS agent and launcher are never on it. Removing them would leave nothing on the device able to report where it is, which is the whole point of the mode.

Security code

Typed on a device, this code does two things:

  • It is the master bypass code used to skip the permissions step during provisioning, when setup is blocked because a required permission hasn't been granted. The device reports as DEGRADED and gets no agent updates until the permissions are granted.
  • Restores a device whose certificate expired while it was offline, for up to 180 days after expiry, without a factory reset. The device keeps its record and policies. It never works for a device that is retired, has its certificate revoked, is in breach mode, or has a disenrollment it hasn't acknowledged yet. {% if not reinstate_enabled %}Turned off below.{% endif %}

{{ bypass_pin }}

It grants no access to this server or its console.
